# Papers

This directory is the public home of manuscripts about Loop Timing Witness. Each manuscript is a
self-contained package under [`submissions/`](submissions/README.md), named with a three-digit
ordering prefix and a descriptive name (`001_descriptive_name`).

No manuscript exists yet, and none will before measured runs exist. A package holds its source,
bibliography, figures, build instructions, citation metadata and the generated, inspected PDF, and
rebuilds from a clean checkout with its documented toolchain. A package directory is a working
record, not evidence that a manuscript has been submitted or accepted.
